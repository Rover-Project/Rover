# ContinuousFocus: AutoFoco e Captura de Imagem

Este exemplo demonstra a utilização básica do módulo de câmera da `roverlib` com o foco contínuo ativado (Auto-Focus). Ele inicializa a transmissão de vídeo e permite a captura de imagens de alta resolução sob demanda.
