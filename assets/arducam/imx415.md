# Arducam IMX415
Descrição técnica e tutorial de uso do módulo de câmera Raspberry Pi **Arducam IMX415**.

---

## Ficha Técnica — Módulo de Câmera Arducam IMX415

- **Produto:** Arducam IMX415 MIPI Camera Module  
- **Plataforma compatível:** Raspberry Pi (5 / 4B / 3B+ / 3 / 2 / CM3 / CM4 / Zero W / Zero 2 W)  
- **Tipo de sensor:** Sony STARVIS IMX415, CMOS 1/2.8"  
- **Resolução máxima:** 8.3 MP — 3840 × 2160 (4K)  
- **Pixel:** 1.45 µm × 1.45 µm  
- **Tecnologia de baixa luz:** STARVIS back-illuminated (alto desempenho em pouca luz)  
- **Interface de saída:** MIPI CSI-2  
- **Formato de saída:** RAW10  
- **Taxa de quadros típica:** ~15.75 fps @ 3864 × 2192  

---

## Óptica

- **Tipo de lente:** Fixa (Fixed Focus)  
- **Montagem da lente:** M12  
- **Campo de visão (FOV):** Diagonal 104° × Horizontal 88° × Vertical 47°  
- **F-number:** F1.0 ±10%  
- **Distância de foco:** 3 m — ∞  
- **Filtro IR:** Integrado 650 nm (IR cut)  

---

## Elétrico & Mecânico

- **Alimentação:** 3.3 V  
- **Consumo máximo:** ~1 W  
- **Temperatura de funcionamento:** 0 °C a 70 °C  
- **Dimensões do módulo:** ≈ 24 mm × 25 mm  

---

## Libcamera

O módulo Arducam IMX415 foi projetado para funcionar com **Raspberry Pi OS (Bookworm ou posterior)** utilizando a stack **libcamera**, que é o sistema oficial e moderno de captura de imagem do Raspberry Pi.

> O driver legado (`raspistill`, `raspivid`) **não é compatível** com este módulo.

---

## Conexão do Módulo

1. Desligue completamente o Raspberry Pi.
2. Localize a porta de câmera **CSI** na placa (próxima ao conector HDMI).
3. Levante cuidadosamente a **trava preta** do conector.
4. Insira a **fita flexível (flat cable)** com os contatos metálicos voltados para o conector da placa.
5. Pressione suavemente a trava para baixo para fixar o cabo.
6. Utilize o cabo adequado:
   - 15 pinos → 22 pinos (Raspberry Pi Zero / CM)
   - 22 pinos → 22 pinos (Raspberry Pi 4 / 5)
7. Verifique se a fita está bem encaixada e alinhada.

---

## Preparando o Raspberry Pi OS

Antes de utilizar a câmera, atualize o sistema operacional para garantir compatibilidade com o libcamera.

No terminal, execute:

```bash
sudo apt update
sudo apt full-upgrade -y
sudo reboot
```
Isso garante:
- Kernel atualizado
- Drivers corretos
- Compatibilidade com o sensor IMX415

---
## Instalação da libcamera
Nas versões atuais do Raspberry Pi OS, o libcamera normalmente já vem instalado.
Ainda assim, é recomendado instalar (ou reinstalar) os pacotes principais:

```bash
sudo apt install -y libcamera-apps libcamera-dev
```
Pacotes instalados:
- ``rpicam-apps``: Ferramentas de teste (``rpicam-hello``, ``rpicam-still``, ``rpicam-vid``).
- ``libcamera-dev``: Bibliotecas e headers para desenvolvimento.


---
## Verificando suporte à câmera
Após a instalação, execute o comando abaixo para verificar se o módulo foi reconhecido:

```bash
rpicam-hello -t 10000
```

Resultado esperado:

- Uma janela de preview da câmera é exibida durando 10 segundos.
- Nenhuma mensagem de erro como “No cameras available”;
- Resolução próxima a 4K (3840 × 2160).

Se isso ocorrer, a câmera está corretamente configurada e pronta para uso.

---

## Alguns comandos 

### Captura de imagem 
```bash 
rpicam-still -o imagem.jpg
```

### Captura de vídeo 
```bash 
rpicam-vid -t 5000 -o video.h264
```

- ``-t 5000``: tempo de captura em milissegundos.
