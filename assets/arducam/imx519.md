# Arducam IMX519 Autofocus
Descrição técnica e tutorial de uso do módulo de câmera **Arducam IMX519 Autofocus** para Raspberry Pi.

---

## Ficha Técnica - Módulo de Câmera Arducam IMX519 Autofocus

- **Produto:** Arducam IMX519 Autofocus Camera Module (SKU B0371)  
- **Sensor:** Sony IMX519, CMOS 16 MP (4656 × 3496)  
- **Tamanho do sensor:** Type 1/2.53″  
- **Tamanho de pixel:** 1.22 µm × 1.22 µm  
- **Resolução máxima:** 4656 × 3496 (16 MP)  
- **Interface de saída:** MIPI CSI‑2  
- **Formato de saída:** RAW10/8, COMP8  
- **Filtro de infravermelho:** Sim (IR-cut)  
- **Autofoco:** Integrado (PDAF + CDAF) - controle de foco por software
- **Campo de visão aproximado:** ~80° diagonal  
- **Velocidade de vídeo típica:** 1920 × 1080 - 30 fps, 1280 × 720 - 60 fps  
- **Compatibilidade com Raspberry Pi OS:** libcamera suporta uso nativo (Bullseye/Bookworm)  

---

## Conexão física

1. Desligue o Raspberry Pi.  
2. Localize a porta **CSI/MIPI-CSI-2** (perto do HDMI).  
3. Levante a trava do conector.  
4. Insira a fita flexível com os contatos metálicos virados para o conector do Raspberry Pi.  
5. Prenda a trava suavemente para fixar o cabo.  
6. Use o cabo correto (15 pinos → 22 pinos ou 22 pinos → 22 pinos, conforme seu modelo).  

---

## Requisitos de software

### Sistema Operacional

- **Raspberry Pi OS Bookworm** (recomendado)  
- **Raspberry Pi OS Bullseye** com libcamera  

> O sistema precisa ter suporte nativo a libcamera para reconhecer e usar corretamente o módulo.

---

## Preparando o Raspberry Pi OS

Atualize o sistema. No terminal:

```bash
sudo apt update
sudo apt full-upgrade -y
sudo reboot
```

Instale os pacotes de câmera:

```bash
sudo apt install libcamera-apps libcamera-dev -y
```
Isso garante que seus aplicativos libcamera estejam disponíveis.

## Testes básicos com libcamera 

### Preview de câmera 
```bash
libcamera-hello -t 5000
```
Se a câmera estiver conectada corretamente, você verá o preview.

### Captura de imagem 
```bash 
libcamera-still -o imagem.jpg
```

### Gravação de vídeo 
```bash 
libcamera-vid --width 1920 --height 1080 --framerate 30 -t 5000 -o video.h264
```

## Controle de foco (Autofocus)
O módulo IMX519 com Autofocus permite controle de foco por software.
A documentação oficial do driver e exemplos de uso estão disponíveis na Wiki e guias da Arducam.

### Considerações 
- A lente com autofoco pode ajustar a distância de foco automaticamente, permitindo foco próximo (~10 cm).

- A saída de vídeo típica é Full HD a 30 fps ou HD a 60 fps, adequado para muitas aplicações de vídeo.

- O uso com libcamera em Raspberry Pi OS Bookworm proporciona suporte mais completo à câmera.

## Tipos de foco suportados 
O driver do libcamera para câmeras com foco motorizado (como a IMX519 AF) oferece:

- Autofoco contínuo
- Autofoco único
- Modo de foco manual (com controle via teclado no preview).

### Autofoco contínuo
Use este comando para deixar a câmera ajustando foco automaticamente o tempo todo:

```bash 
libcamera-still --autofocus-mode continuous -t 0
```
- ``--autofocus-mode continuous``: mantem o autofoco acontecendo.
- ``-t 0``: preview infinito até você apertar Ctrl+C

### Autofoco único 
Esse comando faz a câmera ajustar o foco apenas uma vez:

```bash 
libcamera-still --autofocus-mode auto -t 0
```
- ``--autofocus-mode auto``: única operação de foco.
- ``-t 0``:  preview contínuo

### Foco manual (via teclado no preview)

Se quiser controlar manualmente o foco, siga estes passos:

1. Entre em modo preview:

```bash 
libcamera-still -t 0
```

2. No terminal onde o preview está rodando, você pode usar:

- **f + Enter**: dispara autofoco único.
- **a + Enter**: move foco para mais próximo (incrementa lente).
- **d + Enter**: move foco para mais distante (decrementa lente).

> Esse controle funciona dentro da janela de log do preview.
