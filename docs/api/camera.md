# Câmera

Use `open_camera()` (ou a seção `camera:` do `config.yaml`) para obter a câmera certa automaticamente: `Camera` na Raspberry Pi, `Webcam` no PC.

Mais detalhes e exemplos no [README do plugin de câmera](https://github.com/Rover-Project/Rover/tree/main/roverlib/src/roverlib/plugins/camera).
